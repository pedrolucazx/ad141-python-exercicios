# AD141 Python Exercicios

Repositorio publico para armazenar os exercicios feitos no curso
[Red Hat Training Presents: Introduction to Python Programming (AD141)](https://www.redhat.com/pt-br/services/training/ad141-red-hat-training-presents-introduction-to-python-programming).

## Estrutura

- `basics/`: exercicios introdutorios de Python com foco em entrada de dados,
  strings, operadores e calculos simples.

## Exercicios concluidos

- `basics/basics_ex01.py`: le um texto e informa a quantidade de caracteres.
- `basics/basics_ex02.py`: le nome e sobrenome e exibe nome completo e iniciais.
- `basics/basics_ex03.py`: faz verificacoes simples em uma string e substitui letras.
- `basics/basics_ex04.py`: analisa o primeiro e o ultimo caractere de uma frase.
- `basics/basics_ex05.py`: calcula a area de um circulo a partir do raio.
- `basics/basics_ex06.py`: multiplica dois numeros inteiros e documenta o erro com decimal.
- `basics/basics_ex07.py`: repete uma string com base em um numero informado.
- `basics/basics_ex08.py`: calcula potencia usando base e expoente.

## Como executar

Os scripts sao interativos. Exemplo:

```bash
python3 basics/basics_ex01.py
```
